# 💸 AI Expense Tracker (Flutter + Flask + Machine Learning)

An **AI-powered Expense Tracker** that helps users automatically categorize, visualize, and forecast their expenses using **Machine Learning**, **Flutter**, and **Flask**.  
It intelligently detects spending patterns, predicts expense categories, and provides smart insights with anomaly detection and budget forecasting.

---

## 🚀 Features

✅ **AI-based Categorization**
- Predicts expense categories (e.g., Food, Travel, Rent) using NLP & keyword mapping.  
- Expands dynamically — if no category matches, creates a new one automatically.  

✅ **Interactive Dashboard**
- Real-time expense tracking and category-wise charts.  
- Local storage using Hive (works offline too).  

✅ **Smart Insights**
- Expense summarization (AI-generated monthly breakdown).  
- Budget forecasting using Linear Regression.  
- Anomaly detection with Isolation Forest (find unusual spending).

✅ **Modern Flutter UI**
- Gradient background, custom icon, and Material 3 support.  
- Light & dark themes, optimized for macOS, iOS, and Chrome.  

✅ **Fully Deployed**
- Flask backend hosted on Render  
- Flutter frontend running locally or on macOS/iOS  

---

## 🧠 Tech Stack

**Frontend:**  
- Flutter, Dart  
- Hive for local data storage  
- HTTP package for backend communication  

**Backend (ML):**  
- Flask (Python API)  
- Pandas, Scikit-Learn, Joblib  
- Isolation Forest, Linear Regression  

**Deployment:**  
- Render (Flask backend hosting)  
- macOS/iOS for Flutter app execution
